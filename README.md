# scioly.app

Team-internal Science Olympiad ops + practice platform.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Stack

React + Vite + TypeScript · Tailwind CSS · React Router · Zustand (next) · Supabase (Plan 02)
